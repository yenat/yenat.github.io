AI Mathematician

A prover that combines search, the Vampire and Duper automated provers, Lean 4 and a language model that learns from Lean's error messages. It runs on a 999-theorem library of logic, set theory, arithmetic, ordinals and surreal numbers.

Each gain came from measuring why the last version failed. One test showed that 73% of LLM replies were empty. Another showed that only 7 of 257 goals had every lemma they needed in view, and fixing that one added 77 proofs.

All 877 proofs are stored as exact Lean scripts. One command re-checks them from scratch, each in a fresh process, and the guard rejects incomplete output or any axiom outside the allowed set. The latest result: 877 of 877.

github.com/yenat/ai-mathematician
Theorems proved, by version

v4+ adds results from earlier experiments. v8 stopped after 85 of 167 goals, once analysis showed missing lemmas were no longer the main cause of failure.

Megalodon to Lean 4

A translator that moves formal mathematics between two proof assistants, then proves the translation is faithful. The Lean output is read back out of Lean, rebuilt as Megalodon terms and hashed by Megalodon's own code.

A translation that is wrong in a self-consistent way still type-checks, so Lean alone cannot catch it. This round trip found three real bugs that Lean's kernel could not. As a negative control, all 5,030 deliberately perturbed terms got a different hash.
